# 验证范围

完整软件检查 273 项通过。固件补丁生成与已验证的 R11 镜像逐字节一致，SHA-256 为 `f5758123281d5cf96f991417447aa41652418af10de68fea6d2a142cf39942e7`。

本片使用一台硬件 2.4、Bootloader 4.0、LCD 0x9488 的真实 DS100，客户端 0.5.5.dev1。七段实机录制均通过菜单／位置／档位或文件结果检查，连续移动交付 11 步，录制后恢复原设置。录制中有 1 次自动重同步，不能称为全程无停顿。

视频的鼠标事件由程序内 Qt 自动化执行，轨迹、点击圈和局部放大作为讲解提示。设备画面和响应来自实际 USB，不是模拟器。30 fps 是视频文件帧率，不是仪器新帧或采样率承诺。旁白为合成语音。

之前严格控制检查 7 项、非零偏移检查 8 项通过。保持组合可见反馈约 0.26–0.30 秒，M 菜单约 1.04–1.24 秒。R11 本轮以控制和菜单状态为主，未完成新的全模式逐像素比较。R10 菜单曾完成 153600 像素零差异比较。

原始 ARM 指令执行测试使用模拟的 USB/LCD/RAM 边界，不能替代物理设备验证。完整 MCU Flash／校准备份、正式回退、所有硬件版本、168 MHz USB 策略下的测量准确性和最高采集模式均未验证。原生实时采样与绝对运行／停止服务尚未绑定。

机器可读摘要见 [验证摘要](../evidence/r11-validation.json)。
