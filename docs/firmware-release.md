# R11 固件补丁与升级

**Attention：刷写第三方固件有损坏设备的风险，请谨慎使用。**

只在一台 DS100 硬件 2.4、Bootloader 4.0、LCD 0x9488 上验证。没有 SWD 恢复工具、完整 MCU Flash 或校准备份。USB 文件备份不是 MCU 固件备份，不能保证恢复设备。

## 生成文件

1. 完整解压 `DS100-Firmware-R11-Patch-Windows.zip`，保留 `_internal` 和 `r11`。
2. 运行 `DS100-Prepare-R11.exe`。它从固定官方来源下载底包，并检查哈希。
3. 确认工具输出 `firmware-output/atk_dso.bin` 和上述 R11 哈希。

网络失败时可手动下载固定官方文件，再运行：

```powershell
DS100-Prepare-R11.exe --base 路径\atk_dso_v_4_8.bin
```

源代码入口为 `python tools/prepare_firmware.py --base 路径\atk_dso_v_4_8.bin`。生成工具只创建本地文件，不访问或刷写设备；已有同名文件且内容不同时拒绝覆盖。

## 按原机升级流程操作

1. 确保电量充足，备份用户文件，并核对硬件／引导版本。
2. 关机。按住 A，再长按 P，进入独立升级模式，连接电脑。
3. 将校验后的文件复制为升级盘中的 `atk_dso.bin`，等待完成，再安全弹出。
4. 拔下 USB，按 M 执行升级。等待设备完成，不要中途断电。
5. 升级后停在普通波形界面，重新连接数据线，使用 0.5.5 或更新客户端。

已经安装 R11 的设备不需要重刷。视频使用已经安装的设备演示控制，升级步骤为讲解卡片，没有重演刷写。

## 已知边界

168 MHz USB 时钟策略下的最高采集模式、时基／校准准确性未验证。正式回退流程未完成实机验证。M 菜单仍约一秒，偶发重同步会停顿。R11 使用新的原机按键读取确认，需要客户端 0.5.5 或更新版本。
