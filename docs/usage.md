# 使用说明

[B站完整教程与实机演示](https://www.bilibili.com/video/BV1tHsW6kEsE/)（约 8 分 07 秒，R11 + 0.5.6.dev1）· [章节导航](video.md)。视频保留鼠标点击提示和实际响应等待。

**Attention：刷写第三方固件有损坏设备的风险，请谨慎使用。**

在普通 Windows 用户文件夹完整解压上位机，保留 EXE 旁的 `_internal`。使用 rle7 时，在示波器的 USB 菜单保存 `PC Remote at startup: ON`，关机再开机。停在波形界面并连接数据线，打开 0.5.14.dev3，程序会自动连接。保存 OFF 后重启可关闭上位机功能。USB 菜单中的 `USB Files (read-only)` 为独立操作。

仍使用 R11 的设备可按视频操作。R11 的按键确认需要 0.5.5 或更新上位机。完全关机的设备需要在实机按 P 开机。

顶部有连接、镜像／暂停、截图、快捷与更多菜单。底部原机面板保留四键、每键的按住／双击，以及双拨轮。旋钮可拖动或用鼠标滚轮操作，两侧按钮可点按或按住连续调节。

| 操作 | 含义 |
| --- | --- |
| P 短按 | 按原机规则切换运行／暂停 |
| P 按住 | 原机长按关机，慎用 |
| A | 自动设置，原机可能忙数秒 |
| M | 打开菜单 |
| E | 退出／回中，取决于原机界面 |
| E 下方“双击” | 切换通道 |
| 按住 M + 拨轮Ⅰ | 水平左／右移动 |
| 按住 M + 拨轮Ⅱ | 垂直下／上移动 |
| 按住 E + 拨轮Ⅰ | 时基减小／增大秒每格 |
| 按住 E + 拨轮Ⅱ | 当前通道量程减小／增大伏每格 |

“按住”是保持开关，再点一次松开。使用快捷面板前先松开原机面板中的保持键。P、A、M 的双击发送两次短按，具体效果沿用原机规则；没有额外定义的新功能。

顶部“快捷”提供具名操作，免去先按住再转轮的步骤。方向按钮按住连续移动，松开或窗口失去焦点即停止。快捷动作最多排队 8 项，按钮执行时仍可点击。第一行右侧的“⋯”可选择常用按钮。

换档保留原机位置关系，偏移的物理单位数值会随每格单位缩放。例如 −1.25 ns 在时基加倍后变为 −2.50 ns，反向换档恢复，不是归零，也不是保持物理单位数值恒定的新模式。

截图直接保存原始 480 × 320 PNG 到系统“图片 / DS100”。更多菜单可另存为、打开截图目录、查看 CSV/BMP、连接信息及原始 1:1 显示。CSV/BMP 是设备保存文件，不是实时采集服务。

首次连接会执行设备身份检查，可能需要数秒；连续操作不重复查询。同一时间只打开一个连接设备的上位机窗口。多个客户端同时读取会干扰绘图序号。视频使用真实 USB 设备、程序内 Qt 鼠标事件，并把轨迹、点击圈及局部放大视图加入画面；这些提示不改变设备响应。

M 菜单需要约一秒建立基准，AUTO 可能需要数秒，偶发重同步仍会造成停顿。界面帧率跟随当前硬件状态，不保证固定帧率。充电电流和测量校准并未由上位机验证。
